#+description: What a few more Org features look like on the page: callouts, a table, a quote and footnotes.

Org has more than paragraphs and lists. Here is how a few of its other pieces come out of the default layout.

* Callouts

#+begin_note
A note block becomes =<div class="note">=, as Org writes it. The style sheet decides how it looks.
#+end_note

#+begin_tip
Write the block in Org as =#+begin_tip= and =#+end_tip=.
#+end_tip

#+begin_warn
Callouts are for asides. A page made of them is hard to read.
#+end_warn

* A table

| Piece      | Org writes        | The page shows      |
|------------+-------------------+---------------------|
| Heading    | =* Title=         | an =h2= with a link |
| Emphasis   | =*bold*=, =/italic/= | *bold*, /italic/  |
| Code       | =~code~=          | ~code~              |
